# Easy Life v0.9.1: much smaller download

Same app as v0.9.0, packed for real phones only: the download is far smaller, which matters on mobile data. Installs over v0.9.0 and keeps your data.

Also new since v0.9.0:
- The bottom bar stays usable at Android's largest font size (icons are never cut off).
- "Swap languages" in Urdu Helper is read out by TalkBack.

## What to test on your phone
1. Install `EasyLife.apk` over v0.9.0 (allow "Install unknown apps" if asked): your demo data or real data is still there.
2. Android Settings → Display → Font size → largest. Open Easy Life: the bottom bar shows all icons and labels; Today, Bijli Guard and Settings scroll and read well. Set the font back afterwards.
3. Urdu Helper: translate a sentence offline (after the model download) to confirm the translation library still works.
4. Scan → Try a sample (fictional) → Sample LESCO bill: text is read on the phone as before.
